# ☕ Coffee Shop Sales Analysis Dashboard

A complete **Power BI Sales Analytics Dashboard** built to analyze coffee shop sales performance, customer purchasing behavior, product trends, and store-level insights using interactive visualizations.

---

# 📌 Project Overview

This project focuses on transforming raw coffee shop transaction data into meaningful business insights using **Power BI**.

The dashboard helps analyze:

* Sales performance
* Product category trends
* Customer ordering patterns
* Time-based sales behavior
* Store location performance

The report is designed with interactive visuals, filters, KPI cards, and trend analysis to support better business decision-making.

---

# 📊 Dashboard Pages

## 1. Sales Report

The Sales Report dashboard provides a complete overview of sales performance.

### Key Metrics

* Total Sales
* Total Orders
* Total Transaction Quantity
* Average Sales

### Visualizations Included

* Sales by Date
* Sales by Product Category
* Sales by Product Type
* Weekday vs Weekend Sales
* Sales by Day Name

### Key Insights

* Coffee generated the highest revenue
* Weekdays contributed more sales than weekends
* Barista Espresso was the top-selling product type

---

## 2. Time Analysis

The Time Analysis dashboard focuses on identifying sales trends over time.

### Visualizations Included

* Monthly Sales Trend
* Daily Sales Trend
* Sales by Day
* Weekday vs Weekend Analysis

### Key Insights

* Sales showed strong growth from January to June
* Peak sales occurred during May and June
* Daily sales remained relatively stable throughout the month

---

## 3. Location Analysis

This dashboard compares sales performance across different store locations.

### Visualizations Included

* Total Sales by Store Location
* Total Orders by Store Location
* Sales by Hour
* Product Quantity by Product Type

### Key Insights

* Hell’s Kitchen recorded the highest sales
* Astoria and Lower Manhattan showed similar order distribution
* Morning hours generated the highest sales activity
